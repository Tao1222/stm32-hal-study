| 区域                                 | 用途                  | 例子                        |
| ---------------------------------- | ------------------- | ------------------------- |
| `USER CODE BEGIN Includes` / `END` | 放头文件                | `#include <stdio.h>`      |
| `USER CODE BEGIN PV` / `END`       | 放全局变量               | `uint8_t rx_buf[3];`      |
| `USER CODE BEGIN 0` / `END`        | 放函数定义、宏             | `fputc`、`#define`         |
| `USER CODE BEGIN 1` / `END`        | `main` 里，外设初始化之前的代码 | 一般很少用                     |
| `USER CODE BEGIN 2` / `END`        | `main` 里，外设初始化之后的代码 | `HAL_UART_Receive_IT`     |
| `USER CODE BEGIN 3` / `END`        | `while(1)` 循环里的代码   | 主循环逻辑                     |
| `USER CODE BEGIN 4` / `END`        | 放回调函数               | `HAL_UART_RxCpltCallback` |
